Paso 1 de 3
📊 Creá tu planilla

Necesitás una copia de la planilla de rutina en tu Google Drive.

  1. Abrí este link y hacé click en "Usar plantilla":
https://docs.google.com/spreadsheets/d/1rNUI4EfiDBk-P9zM5gCauUGOFvDBzsvOD7Rzmuld6v0/copy
✓ Esto crea una copia en tu Drive. La planilla original no se modifica.
  1. Una vez copiada, copiá el ID de tu planilla desde la URL del navegador:
docs.google.com/spreadsheets/d/[ESTE ES EL ID]/edit
Paso 2 de 3
⚙️ Instalá el script

El script conecta la app con tu planilla. Solo tarda 2 minutos.

  1. Abrí tu planilla → menú Extensiones → Apps Script
  2. Borrá todo el código que aparece
  3. Copiá y pegá el código de este link:
https://carioca-ghUb.github.io/gimnasio/script.gs
  1. Dentro del código, reemplazá TU_SHEET_ID con el ID que ingresaste antes:
  1. Guardá (Ctrl+S) con el nombre "Gimnasio"
  2. Click en Implementar → Nueva implementación
  3. Tipo: Aplicación web
  4. Ejecutar como: Yo · Acceso: Cualquier persona
  5. Click Implementar → autorizá los permisos
✓ Google te va a pedir que autorices el acceso a tus Sheets. Es necesario para guardar los datos.
Paso 3 de 3
🔗 Conectá la app

Después de implementar el script, Google te da una URL. Pegala acá:

La URL se ve así:
https://script.google.com/macros/s/XXXX.../exec
🎉

¡Todo listo!

Tu app está conectada con tu planilla. Los datos se guardarán automáticamente cada vez que entrenes.
