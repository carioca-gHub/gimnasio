Paso 1 de 3
📊 Creá tu planilla

Hacé una copia de la planilla de rutina en tu Google Drive:

https://docs.google.com/spreadsheets/d/1rNUI4EfiDBk-P9zM5gCauUGOFvDBzsvOD7Rzmuld6v0/copy
✓ Esto crea una copia en tu Drive. La original no se modifica.
  1. Copiá el ID desde la URL de tu planilla:
docs.google.com/spreadsheets/d/[ESTE ES EL ID]/edit
Paso 2 de 3
⚙️ Instalá el script
  1. Abrí tu planilla → Extensiones → Apps Script
  2. Borrá todo el código que aparece
  3. Entrá a este link, copiá todo el código y pegalo:
https://carioca-ghUb.github.io/gimnasio/script.gs
  1. Dentro del código, reemplazá TU_SHEET_ID con:
  1. Guardá (Ctrl+S) → nombre: Gimnasio
  2. Implementar → Nueva implementación
  3. Tipo: Aplicación web
  4. Ejecutar como: Yo · Acceso: Cualquier persona
  5. Click Implementar y autorizá los permisos
✓ Google te pedirá autorización para acceder a tus Sheets.
